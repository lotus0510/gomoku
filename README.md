# 现代化深度学习五子棋训练系统

## 概述

这是一个基于 AlphaZero 架构的现代化五子棋 AI 训练系统，全面改进了原有的训练流程。

## 核心改进

### 1. MCTS 搜索

- ✅ 实现了轻量级 MCTS（200 次模拟/步）
- ✅ PUCT 公式用于节点选择
- ✅ Dirichlet 噪声增加探索
- ✅ 温度控制（前 30 步探索，后期贪婪）

### 2. 增强的神经网络

- ✅ **10 个残差块**（vs 旧版 3 个）
- ✅ **128 个滤波器**（vs 旧版 64 个）
- ✅ **SE（Squeeze-and-Excitation）注意力机制**
- ✅ 改进的策略头（2 层卷积 + Dropout）
- ✅ 增强的价值头（512 隐藏层）

### 3. 优化的训练策略

- ✅ **修复样本加权**：输家权重 0.0 → 0.3
- ✅ **价值折扣**：gamma=0.99，离终局越远价值越模糊
- ✅ **数据增强**：8 种对称变换，8 倍数据扩充
- ✅ **优先级回放**：根据 TD-error 优先采样重要样本

### 4. 评估体系

- ✅ ELO 评级系统
- ✅ 竞技场对战
- ✅ vs 随机玩家评估

## 快速开始

### 命令行参数

所有参数都支持简写：

| 简写 | 完整参数       | 说明                       | 示例                      |
| ---- | -------------- | -------------------------- | ------------------------- |
| `-f` | `--fast-test`  | 使用快速测试配置（小模型） | `-f`                      |
| `-i` | `--iterations` | 训练迭代次数               | `-i 100`                  |
| `-g` | `--games`      | 每次迭代游戏局数           | `-g 50`                   |
| `-r` | `--resume`     | 恢复训练的模型路径         | `-r checkpoints/model.h5` |

## 训练配置说明

可以在 `training/config.py` 中修改超参数：

```python
class TrainingConfig:

    NUM_RES_BLOCKS = 10      # 残差块数量
    NUM_FILTERS = 128        # 卷积滤波器数
    SE_RATIO = 8             # SE注意力压缩比

    # MCTS
    MCTS_SIMULATIONS = 200   # 每步MCTS模拟次数
    C_PUCT = 1.5             # PUCT探索常数

    # 训练
    BATCH_SIZE = 512         # 训练批次大小
    LEARNING_RATE = 0.001    # 学习率

    # 评估
    EVAL_FREQUENCY = 10      # 每N次迭代评估一次
    EVAL_GAMES = 50          # 评估游戏局数
```

## 常见问题

### Q: 训练时显示"缓冲区数据不足，跳过训练"？

**A:** 游戏局数太少，数据不够一个批次。解决方法：

- 增加游戏局数：`-g 50` 或更多
- 或使用 fast-test 配置（BATCH_SIZE 较小）：`-f`

### Q: 大部分游戏 10 步就结束，是否正常？

**A:** 初期**完全正常**！模型刚开始是随机权重：

- 迭代 1-5：游戏很短（10-15 步）
- 迭代 10-20：开始学会防守（20-30 步）
- 迭代 50+：游戏变长（40-60 步+）
- 如果步数持续增加 = AI 在学习 ✅

### Q: 如何在 fast-test 和完整配置间切换？

**A:**

- **Fast-test**（小模型，快）：`-f -i 20 -g 20`
- **完整配置**（大模型，慢但强）：`-i 10 -g 50`
- **注意**：两种配置的权重**不兼容**，会互相覆盖

### Q: 如何继续上次的训练？

**A:** 使用相同的配置继续运行即可，会自动加载 `latest_model.weights.h5`：

```bash
# 第一次训练
python train_pipeline.py -i 100 -g 50

# 继续训练（会从第101次迭代开始）
python train_pipeline.py -i 200 -g 50
```

### Q: 评估结果什么时候出现？

**A:** 每 10 次迭代评估一次（`EVAL_FREQUENCY = 10`）：

- 迭代 1-9：无评估
- 迭代 10：首次评估 vs 随机玩家
- 迭代 20, 30, 40...：后续评估
