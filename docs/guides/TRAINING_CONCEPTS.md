## 強化學習核心概念

### 基本原理

> **「你獎勵什麼，AI 就學什麼」**

強化學習的 AI 不理解「下好棋」是什麼意思，它只會：
1. 觀察獎勵信號
2. 找出能最大化獎勵的策略
3. 不斷強化這些策略

### 獎勵定義了「成功」

```
好的獎勵 → AI 學習正確的技能
壞的獎勵 → AI 學習錯誤的技能（即使表面上成功）
```

## 獎勵機制的重要性

### 經典案例：OpenAI 賽車遊戲

**預期目標**：讓 AI 學會快速完成賽道

**設計的獎勵**：
- 獲得分數道具：+1
- 完成一圈：+獎勵

**實際結果**：
- AI 發現在起點附近來回轉圈可以不斷吃到分數道具
- 它從不完成賽道，只是無限刷分
- **技術上成功**（高分），但**目標上失敗**（不會比賽）

**問題根源**：獎勵機制獎勵了錯誤的行為

### 五子棋中的考量

在五子棋 AI 訓練中，我們需要避免類似問題：

**潛在陷阱 1：Edge-Rush (邊角速勝)**
- 如果只獎勵「贏」，不考慮步數
- AI 可能學會簡單的邊角進攻套路
- 對手稍微防守就失效

**潛在陷阱 2：過度保守**
- 如果過度懲罰輸棋
- AI 可能學會極度保守的策略
- 不敢進攻，只會拖延

**平衡策略：時間折扣機制**
- 鼓勵高效獲勝（但不過度）
- 保留長期戰略能力
- 避免簡單套路

## 當前獎勵機制實現

### 代碼位置
`train_pipeline_pytorch.py:159-164`

### 基本規則

```python
if winner == 0:
    value = 0.0  # 平局
else:
    base_value = 1.0 if entry['turn'] == winner else -1.0
    # 價值折扣
    value = base_value * (config.VALUE_GAMMA ** steps_to_end)
```

### 詳細說明

1. **勝負判定**
   - 勝利方：基礎值 = +1.0
   - 失敗方：基礎值 = -1.0
   - 平局：值 = 0.0

2. **時間折扣 (Temporal Discount)**
   - 使用折扣因子：`VALUE_GAMMA`（可配置）
   - 公式：`value = base_value × (VALUE_GAMMA ^ steps_to_end)`
   - `steps_to_end`：從當前步到遊戲結束的步數

### 範例計算

假設一局遊戲 50 步結束，黑棋獲勝，`VALUE_GAMMA = 0.995`：

| 步數 | 玩家 | steps_to_end | 基礎值 | 折扣後值 | 說明 |
|------|------|-------------|--------|---------|------|
| 1 | 黑 | 49 | +1.0 | +0.778 | 0.995^49 |
| 25 | 黑 | 25 | +1.0 | +0.882 | 0.995^25 |
| 49 | 黑 | 1 | +1.0 | +0.995 | 0.995^1 |
| 50 | 黑 | 0 | +1.0 | +1.000 | 0.995^0 = 1 |

**關鍵觀察**：
- 最後一步（決勝步）：價值 = 1.000
- 第一步：價值 = 0.778
- 價值差距：22.2%

這鼓勵 AI 快速獲勝，但不會過度激進。

## VALUE_GAMMA 參數詳解

### 參數意義

`VALUE_GAMMA` 是時間折扣因子，控制「離終點越近，決策越重要」的程度。

### 不同值的影響

| VALUE_GAMMA | 50步遊戲第1步價值 | 價值差距 | 效果 |
|------------|----------------|---------|------|
| **1.000** | 1.000 | 0% | ❌ 無效率概念 |
| **0.998** | 0.906 | 7.7% | ✅ 輕微偏好快速 |
| **0.995** | 0.778 | **18.2%** | ✅ **明確偏好快速** |
| **0.99** | 0.605 | 33.1% | ⚠️  可能過度激進 |
| **0.98** | 0.364 | 63.6% | ❌ Edge-Rush 風險 |

### 推薦設定

**當前配置：`VALUE_GAMMA = 0.995`**

理由：
1. ✅ **鼓勵高效**：18.2% 的獎勵差距足以鼓勵快速獲勝
2. ✅ **保留戰略**：第 1 步仍有 77.8% 價值，AI 不會放棄長期布局
3. ✅ **避免 Edge-Rush**：不會過度偏好超短遊戲
4. ✅ **平衡性好**：適用於 15×15 棋盤的複雜度

### 調整指南

**如果遇到以下問題，可以調整：**

| 問題 | 症狀 | 建議調整 |
|-----|------|---------|
| Edge-Rush | 超短局 >30% | 提高至 0.998 |
| 過度保守 | 平均步數 >45 | 維持 0.995 或降至 0.99 |
| 策略品質低 | 勝率振盪大 | 提高至 0.998（減少激進） |

## MCTS 與價值估計

### 價值來源的區別

在訓練過程中，有兩種「價值」：

#### 1. MCTS 搜索價值 (root_value)
- **來源**：MCTS 模擬後的根節點平均價值
- **用途**：記錄和監控（不影響訓練）
- **計算**：`root.total_value / root.visit_count`
- **示例**：MCTS 200 次模擬後，根節點可能 value = +0.23

#### 2. 訓練目標價值 (training value)
- **來源**：遊戲結果 + VALUE_GAMMA 折扣
- **用途**：訓練神經網路的目標
- **計算**：`base_value × (VALUE_GAMMA ^ steps_to_end)`
- **示例**：贏棋的第 10 步，value = +0.951

**重要**：神經網路學習的是**訓練目標價值**，不是 MCTS 搜索價值。

### 訓練流程

```
1. Self-Play 階段:
   ├─ 使用 MCTS 生成策略分布
   ├─ 記錄 root_value（僅用於監控）
   └─ 遊戲結束後計算訓練目標價值

2. 訓練階段:
   ├─ 使用「訓練目標價值」作為標籤
   ├─ 訓練神經網路預測價值
   └─ 更新模型參數

3. 下一輪 Self-Play:
   └─ 使用更新後的神經網路
```

### 價值網路的學習目標

神經網路學習預測：
- **輸入**：當前棋盤狀態
- **輸出**：從當前玩家角度的勝率估計
- **範圍**：[-1, +1]
  - +1：當前玩家必勝
  - 0：勢均力敵
  - -1：當前玩家必輸

**訓練標籤**：使用遊戲結果 + VALUE_GAMMA 折扣計算的價值

## 常見問題

### Q1: 為什麼不用 AlphaZero 原版的 VALUE_GAMMA = 1.0？

**回答**：
- AlphaZero 在圍棋和國際象棋中使用 `1.0`
- 但五子棋的特性不同：
  - 遊戲較短（通常 20-40 步）
  - 存在簡單速勝套路（edge-rush）
  - 需要平衡進攻與戰略

**使用 0.995 的好處**：
- 減少 edge-rush 問題
- 鼓勵高效獲勝
- 保留長期戰略能力

### Q2: VALUE_GAMMA 會影響策略網路嗎？

**回答**：
- **不直接影響**：策略網路學習的是 MCTS 訪問次數分布
- **間接影響**：價值網路的準確度會影響 MCTS 搜索質量
- 如果價值網路因 VALUE_GAMMA 學得更好，策略網路也會受益

### Q3: 如何驗證 VALUE_GAMMA 設置是否合適？

**監控指標**：
1. **平均遊戲長度**：25-45 步為健康範圍
2. **超短局比例**：<20% 為佳
3. **勝率平衡**：黑白勝率在 45-55% 範圍
4. **價值損失**：應穩定下降

**診斷工具**：
```bash
python analysis/diagnose_training.py
```

### Q4: 能否動態調整 VALUE_GAMMA？

**理論上可以**，但不推薦：
- 改變 VALUE_GAMMA 會改變訓練目標
- 已訓練的數據標籤會不一致
- 可能導致訓練不穩定

**建議**：
- 在訓練開始前仔細選擇
- 訓練中保持不變
- 如需調整，建議重新訓練
