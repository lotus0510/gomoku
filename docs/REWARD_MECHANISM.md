# 獎勵機制說明

## 當前實現 (train_pipeline_pytorch.py:159-164)

### 基本規則

```python
if winner == 0:
    value = 0.0  # 平局
else:
    base_value = 1.0 if entry['turn'] == winner else -1.0
    # 價值折扣
    value = base_value * (VALUE_GAMMA ** steps_to_end)
```

### 詳細說明

1. **勝負判定**
   - 勝利方：基礎值 = +1.0
   - 失敗方：基礎值 = -1.0
   - 平局：值 = 0.0

2. **時間折扣 (Temporal Discount)**
   - 使用折扣因子：`VALUE_GAMMA = 0.99`
   - 公式：`value = base_value × (0.99 ^ steps_to_end)`
   - `steps_to_end`：從當前步到遊戲結束的步數

### 範例計算

假設一局遊戲 15 步結束，黑棋獲勝：

| 步數 | 玩家 | steps_to_end | 基礎值 | 折扣後值 | 計算式 |
|------|------|-------------|--------|---------|--------|
| 1 | 黑 | 14 | +1.0 | +0.8687 | 1.0 × 0.99^14 |
| 2 | 白 | 13 | -1.0 | -0.8775 | -1.0 × 0.99^13 |
| 3 | 黑 | 12 | +1.0 | +0.8864 | 1.0 × 0.99^12 |
| ... | ... | ... | ... | ... | ... |
| 14 | 白 | 1 | -1.0 | -0.9900 | -1.0 × 0.99^1 |
| 15 | 黑 | 0 | +1.0 | +1.0000 | 1.0 × 0.99^0 |

### 設計理念

1. **時間折扣的作用**
   - 鼓勵模型學習「越早的決策對最終結果影響越小」
   - 最後幾步的決策最關鍵（折扣接近 1.0）
   - 開局的決策影響較小（折扣較低，約 0.8-0.9）

2. **為什麼使用 0.99？**
   - 相對溫和的折扣
   - 在 15 步遊戲中：第 1 步仍有 86.87% 的價值
   - 在 50 步遊戲中：第 1 步仍有 60.50% 的價值
   - 既考慮長期影響，又強調近期決策

## 與 AlphaZero 原版的對比

### AlphaZero 原版
- **無時間折扣**：所有步驟獎勵相同
- 勝利方所有步驟：+1
- 失敗方所有步驟：-1
- 平局所有步驟：0

### 當前實現
- **有時間折扣**：根據距離遊戲結束的步數調整
- 這種設計更符合某些棋類遊戲的特性

## 對訓練的影響

### 可能的優勢
1. 幫助模型更快學習關鍵決策點
2. 減少早期無關緊要動作的噪音
3. 加速收斂（理論上）

### 可能的問題
1. **可能阻礙長期策略學習**
   - 早期佈局的價值被低估
   - 可能鼓勵短期速勝策略（edge-rush）
2. **與 AlphaZero 原版不同**
   - 原版無折扣的設計經過大量驗證
   - 折扣機制可能不適合五子棋

## 建議調整方向

### 選項 1：移除時間折扣（回歸 AlphaZero）
```python
if winner == 0:
    value = 0.0
else:
    value = 1.0 if entry['turn'] == winner else -1.0
```

### 選項 2：調整折扣因子
```python
VALUE_GAMMA = 0.995  # 更溫和（50步後仍保留78%價值）
VALUE_GAMMA = 1.0    # 完全無折扣（AlphaZero 原版）
```

### 選項 3：使用不同的獎勵塑形
```python
# 範例：給予快速獲勝額外獎勵
if winner != 0:
    base_value = 1.0 if entry['turn'] == winner else -1.0
    # 快速勝利獎勵
    speed_bonus = 1.0 + 0.1 * max(0, (30 - len(game_history)) / 30)
    value = base_value * speed_bonus
```

## 當前問題分析

考慮到目前觀察到的「edge-rush」問題：

**時間折扣可能是誘因之一**
- 9步快速獲勝的第1步：價值 = 1.0 × 0.99^8 = 0.923
- 50步正常獲勝的第1步：價值 = 1.0 × 0.99^49 = 0.612

這意味著：
- 模型學習到「快速獲勝的早期決策」價值更高
- 可能強化了 rush 策略
- 長期戰略被低估

**建議：考慮移除或減弱時間折扣**
