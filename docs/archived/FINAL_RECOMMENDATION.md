## 🔬 理論依據

### 為什麼 VALUE_GAMMA = 0.998（而不是 1.0 或 0.99）？

#### 問題 1：VALUE_GAMMA = 1.0 的問題

```
10步獲勝 reward = 1.0
50步獲勝 reward = 1.0
70步獲勝 reward = 1.0

→ 模型學到：「反正都是獲勝，不在乎步數」
→ 可能出現拖延戰術
→ 遊戲長度可能過長（>60 步）
→ 訓練效率低
```

#### 問題 2：VALUE_GAMMA = 0.99 的問題（已證實）

```
10步獲勝 reward = 0.90
50步獲勝 reward = 0.61

差距 33%！

→ 模型學到：「一定要快！」
→ 追求極端速勝
→ Edge-Rush 策略（10 步第 0 行連珠）
→ 訓練崩潰
```

#### 最佳：VALUE_GAMMA = 0.998

```
10步獲勝 reward = 0.98
50步獲勝 reward = 0.90

差距 8%

→ 模型學到：「快一點更好，但不能犧牲質量」
→ 鼓勵效率
→ 不至於 Rush
→ 平衡策略質量與速度 ✓
```
