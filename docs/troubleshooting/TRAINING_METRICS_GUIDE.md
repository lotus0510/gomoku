# 训练指标参考指南

**目的**: 了解健康训练的指标范围和常见问题诊断
**适用**: 监控训练进度，识别问题

---

## 健康训练指标基准

### 核心指标范围

| 指标 | 健康范围 | 警告范围 | 异常范围 | 说明 |
|------|---------|---------|---------|------|
| **策略损失** | 4.5-5.5 | 5.5-6.0 | >6.0 或 <4.0 | 持续下降是好事 |
| **价值MAE** | 0.70-0.85 | 0.85-0.95 | >0.95 | 越低越好 |
| **胜率** | >85% | 75-85% | <75% | vs随机策略 |
| **游戏长度** | 50-70步 | 40-50或70-80 | <40 或 >80 | 太短=套路化 |
| **平均梯度** | 0.5-5.0 | 0.1-0.5或5-10 | <0.1 或 >10 | 梯度消失或爆炸 |

### 训练阶段预期

#### 初期（迭代1-30）

```
策略损失: 6.0 → 5.3  ✅ 快速下降
价值MAE:  0.98 → 0.77 ✅ 显著改善
胜率:     70% → 90%   ✅ 稳步提升
游戏长度: 60 → 55步   ✅ 正常范围

特征: 快速学习期，指标改善明显
```

#### 中期（迭代30-100）

```
策略损失: 5.3 → 5.0  ✅ 持续优化
价值MAE:  0.77 → 0.75 ✅ 缓慢改善
胜率:     90% → 95%   ✅ 稳定提升
游戏长度: 55 → 60步   ✅ 策略多样化

特征: 稳定期，改善速度放缓但持续
```

#### 后期（迭代100+）

```
策略损失: 5.0 → 4.8  ✅ 接近收敛
价值MAE:  0.75 → 0.73 ✅ 微小改善
胜率:     95% → 97%   ✅ 接近饱和
游戏长度: 60 → 65步   ✅ 稳定

特征: 收敛期，指标稳定，微调优化
```

## 常见问题诊断

### 问题1: 价值网络崩溃（U型MAE）

**症状**:
```
迭代30: MAE 0.77 ✅
迭代60: MAE 0.87 ⚠️
迭代90: MAE 0.95 ❌
迭代120: MAE 1.04 ❌❌
```

**诊断**:
- Value Loss 连续5次以上上升
- MAE从健康值(0.75-0.85)恶化到>0.95
- 游戏长度缩短（套路化）

**解决方案**:
→ 使用[自定义重置策略](../guides/CUSTOM_RESET_GUIDE.md)回滚到健康checkpoint

---

### 问题2: 策略停滞

**症状**:
```
迭代50-70: 策略损失保持在5.3-5.4
          无明显下降趋势
          持续20次迭代无改善
```

**诊断**:
- 策略损失plateaued
- 价值MAE正常
- 探索不足

**解决方案**:
- 提高探索率(DIRICHLET_EPSILON): 0.25 → 0.35
- 提高温度(TEMPERATURE): 1.0 → 1.2
- 增加自我对弈游戏数

---

### 问题3: 套路化

**症状**:
```
游戏长度: 60步 → 45步 → 38步
Top1概率: 25% → 35% → 48%
策略多样性下降
```

**诊断**:
- 模型过度优化单一策略
- 探索不足
- 训练数据缺乏多样性

**解决方案**:
- 提高探索率: 0.25 → 0.40
- 降低温度退火速度
- 清空部分经验池数据

---

### 问题4: 梯度问题

#### 4a. 梯度消失

**症状**:
```
平均梯度: 0.05-0.1
损失几乎不下降
训练停滞
```

**解决方案**:
- 提高学习率: 0.0001 → 0.0002
- 检查网络初始化
- 减小批次大小

#### 4b. 梯度爆炸

**症状**:
```
平均梯度: >15
损失震荡
训练不稳定
```

**解决方案**:
- 降低学习率: 0.0001 → 0.00005
- 启用梯度裁剪
- 检查数据异常值

---

### 问题5: 过拟合

**症状**:
```
训练损失持续下降
评估胜率反而下降
泛化能力差
```

**解决方案**:
- 增加数据增强
- 提高探索率
- 定期清理经验池

## 关键比率和关系

### MAE vs 策略损失

**健康关系**:
```
MAE下降 → 策略损失也下降  ✅ 良性循环
MAE上升 → 策略损失上升    ⚠️ 警告信号
MAE上升 → 策略损失下降    ❌ 价值崩溃征兆
```

### 游戏长度 vs Top1概率

**健康关系**:
```
游戏长度50-70步 + Top1=20-30%  ✅ 多样性好
游戏长度<45步 + Top1>40%       ❌ 套路化
游戏长度>75步 + Top1<15%       ⚠️ 策略不自信
```

### 胜率 vs 探索率

**健康关系**:
```
高探索(ε=0.35) → 胜率85-90%  ✅ 正常
低探索(ε=0.15) → 胜率95%+    ⚠️ 可能过拟合
高探索(ε=0.50) → 胜率<80%    ⚠️ 探索过度
```

## 参数调整建议

### 学习率调整

| 情况 | 当前LR | 调整后 | 原因 |
|------|--------|--------|------|
| 损失plateaued | 0.0001 | 0.00015 | 加速收敛 |
| 训练不稳定 | 0.0001 | 0.00005 | 稳定训练 |
| 梯度消失 | 0.0001 | 0.0002 | 增强信号 |

### 探索率调整

| 情况 | 当前ε | 调整后 | 原因 |
|------|-------|--------|------|
| 套路化 | 0.25 | 0.40 | 增加多样性 |
| 胜率低 | 0.35 | 0.25 | 减少噪声 |
| 策略停滞 | 0.25 | 0.35 | 探索新策略 |

### 批次大小调整

| 情况 | 当前 | 调整后 | 原因 |
|------|------|--------|------|
| 内存不足 | 1024 | 512 | 降低内存使用 |
| 训练不稳定 | 256 | 512 | 增加稳定性 |
| 收敛太慢 | 1024 | 2048 | 加速收敛 |

```
□ 策略损失是否持续下降或稳定
□ 价值MAE是否在0.70-0.85范围
□ 胜率是否>85%
□ 游戏长度是否在50-70步
□ 梯度是否在正常范围
```

```
□ MAE连续3次上升 → 检查Value Loss趋势

□ 胜率<80% → 检查探索率设置

```

## 快速诊断流程

```
1. 检查最近5次迭代的MAE趋势
   ├─ 连续上升 → 使用自定义重置策略
   ├─ 稳定在健康范围 → 继续训练
   └─ 波动但无趋势 → 正常

2. 检查策略损失
   ├─ 持续下降 → 健康
   ├─ Plateaued 20+次 → 提高探索率
   └─ 上升 → 检查数据质量

3. 检查游戏长度
   ├─ 50-70步 → 健康
   ├─ <45步 → 套路化，提高探索
   └─ >75步 → 策略不自信，检查温度

4. 综合评估
   ├─ 所有指标健康 → 继续训练
   ├─ 单一指标异常 → 针对性调整
   └─ 多指标异常 → 考虑重置
```

---

**关键提示**: 价值MAE是最重要的健康指标。如果MAE开始恶化（>0.85），应立即采取行动！
